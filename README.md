# [NOM DE L'AUBERGE] — refonte one-pager

Surf + Moto en axes principaux, auberge en complément.

## Démarrer
1. Ouvre ce dossier dans VS Code.
2. Remplis ce que tu peux dans `docs/BRIEF.md`.
3. Dépose les photos dans `assets/photos/surf`, `moto`, `auberge` (et le logo dans `assets/logo`).
4. Lance Claude Code et colle le prompt 1 de `docs/PROMPTS.md`.

## Arborescence
- `CLAUDE.md` — les règles du projet pour Claude Code
- `docs/BRIEF.md` — les infos à récupérer sur place
- `docs/CONTENU.md` — les textes de la page
- `docs/PROMPTS.md` — la séquence de prompts, étape par étape
- `assets/` — photos, logo, références visuelles
